# Proyecto base - Taller parcial 2

Este proyecto contiene una pequeña calculadora de compras y pruebas automatizadas.

## Estructura

- `src/calculadora.js`: funciones de la aplicación.
- `test/calculadora.test.js`: pruebas automatizadas.
- `package.json`: configuración y comando de pruebas.

## Comando de pruebas

```bash
npm test
```

## Importante

El proyecto contiene deliberadamente una incidencia que debe ser detectada mediante el pipeline y analizada a partir de los resultados de las pruebas. No corrijas el código antes de obtener la evidencia solicitada en las instrucciones del taller.
